# 동물 쇼기 (どうぶつしょうぎ / Dōbutsu Shōgi) 규칙 정리

> 출처: BGG "Let's Catch the Lion!" (id 56796 / 38545), pychess.org/variants/dobutsu,
> chessvariants.com/rules/dobutsushogi, kiddle 요약, japanesechess.org
> 2008년, 키타오 마도카(北尾まどか, 규칙) + 후지타 마이코(藤田麻衣子, 그림) / LPSA

## 1. 보드와 초기 배치

보드: 3열 × 4행. 각 플레이어의 맨 앞줄(상대 진영 끝줄)이 그 플레이어의 "트라이 존".

```
      a    b    c
  1 [기린][사자][코끼리]   ← 후수(Gote) 진영
  2 [   ][병아리][   ]
  3 [   ][병아리][   ]
  4 [코끼리][사자][기린]   ← 선수(Sente) 진영
```

- 각 플레이어 기준: 자기 뒷줄 **왼쪽=코끼리, 가운데=사자, 오른쪽=기린**, 사자 바로 앞에 병아리.
- 배치는 180° 회전 대칭(점대칭)이다.

## 2. 기물과 이동 (전부 1칸씩만)

| 기물 | 원본 | 이동 |
|------|------|------|
| 사자 (Lion) | 왕 | 8방향 1칸 |
| 기린 (Giraffe) | 비차(룩) | 상하좌우 4방향 1칸 |
| 코끼리 (Elephant) | 각행(비숍) | 대각 4방향 1칸 |
| 병아리 (Chick) | 보(폰) | 앞 1칸 |
| 닭 (Hen, 승격 병아리) | 토킨(금장) | 8방향 중 **대각선 뒤 2방향 제외** 6방향 1칸 |

## 3. 승격

- 병아리가 **상대 진영 끝줄(자기 기준 4번째 줄)에 도달**하면 닭으로 승격.
- 승격하는 기물은 병아리뿐. (선택이 아니라 도달 시 승격 — 표준 구현은 강제 승격)
- 닭을 잡으면 **병아리로 되돌아가** 손패에 들어온다.
- **드롭한 기물은 그 자리에서 승격하지 않는다** (끝줄에 드롭해도 병아리 그대로).

## 4. 잡기와 드롭 (쇼기 방식)

- 잡은 기물은 자기 손패가 되고, 이후 자기 턴에 **빈 칸 아무 곳에나 드롭**해 자기 기물로 쓸 수 있다.
- 드롭 = 한 턴(이동 대신).
- 일반 쇼기와 달리 **제약이 거의 없다**:
  - 같은 열에 병아리 2개 드롭 가능 (이후보 금지 없음)
  - 맨 끝줄에 병아리 드롭 가능 (움직일 수 없는 상태여도 OK, 단 승격 안 됨)
  - **드롭한 병아리로 외통(체크메이트) 내도 승리** (타보즈메 금지 없음)

## 5. 승리 조건

1. **캐치(Catch)**: 상대 사자를 잡으면 승리. (= 외통 상태에서 상대가 못 벗어나면 그대로 승리)
2. **트라이(Try)**: 자기 사자가 **상대 진영 끝줄에 도달**하면 승리.
   단, 도달한 그 자리가 **상대에게 잡히는 자리면 안 된다**(도달 시점에 체크가 아니어야 함).

## 6. 무승부

- 같은 국면이 3회 반복되면 무승부.
- 연속 장군(퍼페추얼 체크)도 일반 쇼기와 달리 **무승부**.

## 7. 참고: 게임 이론적 결론

완전 분석(솔브)된 게임이며 **후수 필승**(정확한 플레이 시 78수). 초심자~중급자 수준에서는 무관하지만, AI 난이도 설계 시 참고.

## 8. 확장 변형 (나중에 고려용)

- **고로고로 동물 쇼기(Goro Goro Dōbutsu Shōgi)**: 5×6 보드, 개·고양이 기물 추가.

## 9. 구현 확정 사항 (2026-09-16 결정)

| 항목 | 결정 |
|------|------|
| 트라이 판정 | 사자가 상대 끝줄 도달 + **그 시점에 장군이 아닌 상태**면 승리 |
| 자살수 | **금지하지 않는다.** 사자를 잡히는 자리로 옮길 수 있고, 다음 수에 잡히면 패배 |
| 승격 | 끝줄 도달 시 **자동·강제** 승격 (선택권 없음) |
| 스테일메이트 | 둘 수 있는 수(이동+드롭)가 하나도 없으면 **그 플레이어 패배** |
| 반복 무승부 | **손패 상태 포함**한 전체 국면 기준, 같은 국면 3회 시 무승부 |
| 보드 크기 | **3×4 하드코딩.** 고로고로(5×6) 확장은 하지 않음 |
